# @bushscad/language-server

Language-server implementation and protocol support for BushSCAD editors. This package is distributed as TypeScript source for editor integrations and bundlers.

See [BushSCAD documentation](https://bushscad.byaidan.com/) and the [language project](https://github.com/AidanBoissonneault/BushSCAD-Language) for the language reference and project context.
