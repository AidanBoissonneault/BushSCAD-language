# @bushscad/cli

The command-line compiler and service interface for BushSCAD. The published package includes the bundled runtime and fonts; OpenCascade is installed as a package dependency.

See [BushSCAD documentation](https://bushscad.byaidan.com/) and the [language project](https://github.com/AidanBoissonneault/BushSCAD-Language) for the language reference and project context.
