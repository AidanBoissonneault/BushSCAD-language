# @bushscad/compiler

Compiler pipeline APIs for parsing, resolving, evaluating, and compiling BushSCAD models. This package is distributed as TypeScript source for language tooling and bundlers.

See [BushSCAD documentation](https://bushscad.byaidan.com/) and the [language project](https://github.com/AidanBoissonneault/BushSCAD-Language) for the language reference and project context.
